# Item — NOSH7 Juice Launch Tracker

A lightweight single-page tracker for **NOSH7 Cloud Kitchen's juice product launch** — monitors inventory, sales milestones, and launch progress in one place.

## What It Does

Gives the NOSH7 ops team a dedicated view for tracking the juice product line — from initial inventory counts to sales milestones and launch status updates.

## Key Features

- **Juice product launch tracking** — single source of truth for the launch
- **Inventory monitoring** — track stock levels across juice variants
- **Sales milestone tracking** — measure progress against targets
- **Launch status overview** — at-a-glance view of where the launch stands
- **Lightweight, no login** — open and update instantly

## Tech Stack

- HTML, CSS, Vanilla JavaScript

## Audience

NOSH7 operations team managing the juice product line launch.
